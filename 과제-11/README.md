# 과제 11: 삽입 정렬과 쉘 정렬의 성능 비교

## 1. 실험 개요

- 무작위 정수 데이터(`rand()`, 시드 12345 고정)를 생성하고, 동일한 원본의 복사본을 세 알고리즘에 각각 적용했다.
- 비교 대상
  1. 삽입 정렬 (Insertion Sort)
  2. 쉘 정렬 - 기본 간격 (n/2, n/4, ..., 1)
  3. 쉘 정렬 - Knuth 간격 (1, 4, 13, 40, ... 중 n보다 작은 최대값부터 역순)
- 측정 기준: `a[j] > key` 처럼 **데이터 값끼리 비교한 횟수**만 센다. 반복문 인덱스/종료 조건 검사, 데이터 생성, 배열 복사는 제외했다.
- 모든 정렬 후 오름차순 정렬 여부를 검증했으며, 모든 경우 정상 정렬되었다.

### 실행 방법

```bash
gcc -O2 -o sort_compare sort_compare.c
./sort_compare
```

## 3. 분석

### 3.1 데이터 크기 증가에 따른 비교 횟수 변화

**삽입 정렬**은 n이 2배가 될 때마다 비교 횟수가 거의 정확히 약 4배가 된다(3.96~4.07배). 또한 모든 n에서 비교 횟수 ÷ n² 값이 0.2485~0.2533으로 거의 일정하여 **n²/4에 가깝다**. 무작위 데이터에서 삽입 정렬의 평균 비교 횟수가 약 n²/4라는 이론과 일치하며, 시간 복잡도가 O(n²)임을 실험으로 확인할 수 있다. 16,000개에서 약 6,360만 회, 20,000개에서 약 1억 회까지 늘어났다.

**쉘 정렬**은 n이 2배가 될 때 약 2.3~2.6배만 증가한다. 4배가 아니라 2배보다 약간 큰 수준이므로 n log n보다는 크고 n²보다는 훨씬 작은 증가율, 대략 n^1.2~n^1.4 정도의 증가 양상이다. 20,000개에서도 기본 간격은 약 62만 회, Knuth는 약 57만 회에 그쳤다.

### 3.2 삽입 정렬과 쉘 정렬의 성능 차이

두 방식의 격차는 n이 커질수록 벌어진다. 삽입 정렬 대비 쉘 정렬(Knuth)의 비교 횟수는 n=1,000에서 약 18배 적었지만, n=20,000에서는 약 175배 적었다. 삽입 정렬은 n²로, 쉘 정렬은 그보다 훨씬 느리게 증가하기 때문에 **데이터가 클수록 쉘 정렬의 이점이 커진다**.

원인은 삽입 정렬의 이동 방식에 있다. 삽입 정렬은 원소를 한 칸씩만 이동시키므로, 무작위 데이터에서 원소가 제자리를 찾기까지 평균 i/2번의 비교(이동)가 필요하다. 쉘 정렬은 처음에 큰 간격으로 멀리 떨어진 원소끼리 비교·교환하기 때문에, 한 번의 이동으로 원소가 목적 위치 근처까지 크게 이동한다. 이렇게 큰 간격 단계에서 데이터가 대략 정렬된 상태가 되면, 마지막 gap=1 단계(삽입 정렬)에서는 각 원소가 제자리에서 몇 칸 이내에만 있으므로 비교가 거의 n회 수준으로 줄어든다. 삽입 정렬은 "거의 정렬된 데이터에서 매우 빠르다"는 성질이 있으며, 쉘 정렬은 이 성질을 이용한 알고리즘이다.

### 3.3 기본 간격과 Knuth 수열의 차이

모든 n에서 **Knuth 간격이 기본 간격보다 비교 횟수가 적었다**. 감소율은 약 8~13.5%이다. 격차는 삽입 정렬과 쉘 정렬 사이의 격차(수십~수백 배)에 비하면 작지만, 일관되게 나타났다. 또한 n이 커질수록 n log n으로 나눈 값(기본: 1.47→2.18, Knuth: 1.35→2.00)이 두 방식 모두 커지는데, 기본 간격이 더 가파르게 증가한다. 즉 n이 매우 커지면 차이가 더 벌어질 가능성이 있다. 다만 이번 실험 범위(n ≤ 20,000)만으로는 점근적 차이를 단정할 수 없다.

감소율이 n에 대해 단조롭지 않다는 점도 눈에 띈다(2,000에서 12.0%, 4,000에서 7.8%, 16,000에서 13.5%, 20,000에서 8.0%). 기본 간격은 n/2, n/4, ...로 정해지므로 **n 값 자체의 약수 구조에 따라 간격 수열이 달라지고**, 그에 따라 효율이 달라지기 때문으로 보인다. 예를 들어 n=16,000은 8000, 4000, 2000, 1000, 500, 250, 125로 처음 여러 단계의 간격이 모두 서로 약수·배수 관계에 있다. 반면 Knuth 수열은 n과 무관하게 항상 같은 수열을 사용하므로 변동이 더 작다. (이 설명은 간격 구조를 근거로 한 해석이며, 이 실험만으로 인과관계를 증명한 것은 아니다.)

한편 이번 실험은 무작위 데이터 한 세트(시드 고정)에 대한 결과이므로, 다른 시드나 반복 실험에서는 수치가 조금 달라질 수 있다. 다만 삽입 정렬의 n²/4 일관성과 쉘 정렬 간의 일관된 우열은 모든 크기에서 같은 방향으로 나타났다.

### 3.4 간격 수열이 쉘 정렬 성능에 영향을 주는 이유

1. **간격이 서로 약수·배수 관계이면 정보가 중복된다.** 기본 간격(2의 거듭제곱 형태)에서는 큰 간격 단계에서 정렬된 부분 수열이 작은 간격 단계에서도 같은 원소끼리만 묶이는 경우가 많다. 예컨대 간격이 짝수인 동안은 짝수 위치 원소와 홀수 위치 원소가 서로 전혀 섞이지 않다가, 간격 1이 되어서야 처음으로 만난다. 이 경우 앞 단계의 정렬 효과가 마지막 단계에 충분히 전달되지 않아, 마지막 단계에서 비교·이동이 많이 남게 된다. 최악의 경우(예: 짝수 위치와 홀수 위치에 큰 값/작은 값이 몰린 입력) 기본 간격은 O(n²)까지 나빠질 수 있다.
2. **Knuth 수열(1, 4, 13, 40, ...)은 약 3배씩 증가하며 서로 배수 관계가 되지 않는다.** 따라서 각 단계에서 서로 다른 원소 조합이 섞이고, 앞 단계의 정렬 성과가 다음 단계에 더 효과적으로 반영된다. 이론적으로도 Knuth 수열은 최악의 경우 O(n^1.5)가 보장된다.
3. **단계 수와 단계당 비용의 균형.** 간격이 너무 촘촘하면 단계가 많아져 단계마다 최소 약 n회의 비교가 들고, 너무 성기면 각 단계에서 원소당 이동 거리가 커진다. 3배씩 줄이는 Knuth 수열은 기본 간격(2배씩)보다 단계 수가 적으면서도, 이전 단계에서 이미 정렬된 정도가 충분하여 각 단계의 추가 비교량이 작게 유지된다.

### 3.5 결론

- 삽입 정렬은 n²/4에 거의 정확히 비례(n이 2배면 약 4배)하는 반면, 쉘 정렬은 n이 2배일 때 약 2.3~2.6배만 증가해 n이 클수록 격차가 커진다(n=20,000에서 약 160~175배 차이).
- 쉘 정렬의 성능은 간격 수열에 의존하며, 이번 실험에서 Knuth 간격은 기본 간격보다 모든 크기에서 약 8~13.5% 적은 비교로 정렬했다.
- 이 차이는 서로 배수 관계가 아닌 간격이 앞 단계의 정렬 효과를 다음 단계에 더 잘 전달하기 때문이며, 기본 간격은 n의 약수 구조에 따라 효율이 들쑥날쑥한 반면 Knuth 간격은 더 안정적이었다.
